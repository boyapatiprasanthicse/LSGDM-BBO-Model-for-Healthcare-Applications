## 🧠 Abstract

This research proposes a **Large-Scale Group Decision-Making (LSGDM)** model using **MapReduce** and an innovative **Biogeography-Based Optimization (BBO) with Fuzzy C-Means (FCM)** technique for effective healthcare management within Industry 4.0. It integrates advanced preference modeling through **2TFLR**, robust feature extraction using **LSTM**, and optimized classification via **Extreme Learning Machine (ELM)** fine-tuned by **Tree Growth Algorithm (TGA)** — delivering highly accurate automated disease diagnosis for big healthcare datasets.

---

## 🚀 Key Contributions

- **Big Data Compatible Healthcare Decision Model:**  
  Introduced MR-LSGDM using Hadoop MapReduce architecture.

- **Innovative Clustering Approach:**  
  Developed a novel **BBO-FCM** for improved decision-maker clustering.

- **Advanced Classification Pipeline:**  
  Integrated **LSTM-based feature extraction** with **Optimal ELM classification**.

- **Superior Performance:**  
  Achieved **up to 99.1% accuracy** with **very high ROC values (99.98%)** across multiple experimental runs.

- **Real-World Relevance:**  
  Designed for healthcare IoT data analysis, enhancing telemedicine and healthcare analytics applications.

---

## 🌟 Advantages of the Proposed Approach

- **Optimization-Powered Clustering:**  
  Biogeography-Based Optimization (BBO) improves the initialization of Fuzzy C-Means (FCM), overcoming local minima issues common in traditional clustering methods.

- **High Scalability:**  
  Use of **Hadoop MapReduce** allows efficient processing of massive healthcare data, suitable for real-world Big Data environments.

- **Robust Feature Extraction:**  
  LSTM-based architecture ensures capturing temporal dependencies, boosting classification reliability.

- **Accelerated Classification:**  
  Optimal ELM (Extreme Learning Machine) classifier achieves faster convergence and superior generalization with fewer computational resources.

- **Adaptive Model Tuning:**  
  Tree Growth Algorithm (TGA) optimizes ELM parameters dynamically, improving model performance without manual hyperparameter tuning.

- **Superior Metrics:**  
  Outperforms CNN, CNN-LSTM, and other models by 2–5% in terms of accuracy, F1-score, and ROC.
